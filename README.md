## ✨ Features

- 🌗 **Dark / Light Mode Toggle** — System preference detected with manual override
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- ⚡ **No Frameworks** — Pure HTML, CSS, and JavaScript (zero dependencies)
- 🎨 **Custom Design System** — Consistent tokens for typography, spacing, and color
- 📬 **Working Contact Form** — Powered by Netlify Forms (no backend required)
- 🔠 **Smooth Animations** — Fade-in scroll reveals and interactive hover states
- ♿ **Accessible** — Semantic HTML, keyboard navigation, ARIA labels, skip links
- 🔍 **SEO Ready** — Proper meta tags and semantic structure

## 🏁 Getting Started

### View Locally

No build tools or dependencies required. Simply clone and open:

```bash
git clone https://github.com/Devanshuhc29/My-Portfolio.git
cd My-Portfolio
```

Then open `index.html` in your browser — or use VS Code's **Live Server** extension for hot reload.

### Making Changes

1. Edit any `.html`, `css/`, or `js/` file
2. Test locally in your browser
3. Push changes to GitHub:

```bash
git add .
git commit -m "Your change description"
git push
```

GitHub Pages auto-deploys on every push to `main`. ✅

## 🚢 Deployment

This project is deployed on **GitHub Pages** directly from the `main` branch.

| Step | Action |
|------|--------|
| 1 | Go to repo **Settings → Pages** |
| 2 | Set Source to `main` branch, `/ (root)` |
| 3 | Click **Save** |
| 4 | Live at `https://devanshuhc29.github.io/My-Portfolio` |

> The contact form uses **Netlify Forms** — it works when deployed on Netlify. On GitHub Pages, the form UI is visible but submissions won't be captured without a backend or third-party service.
